# 02.approved — Specs đã review và approved

Chứa các spec trạng thái `APPROVED`. Đợt duyệt ban đầu diễn ra ngày 14/11/2026. Người/ngày/căn cứ xác nhận ghi ở đầu từng file và trong [lịch sử duyệt](../LICH-SU-DUYET.md#approved-2026-11-14).

Một spec tại đây có thể đã có mã, còn thiếu một phần giao diện hoặc đang chờ nghiệm thu. Xem báo cáo Txx để biết phần còn lại và [danh sách archived](../03.archived/README.md) để xem bằng chứng của các mục đã hoàn tất.

Triển khai theo spec đã approved và task gốc. Khi nghiệm thu xong, ghi commit và liên kết báo cáo/log, chuyển sang `03.archived`. Nếu thay đổi yêu cầu trước khi hoàn thành, đưa về `01.draft` để review lại.
