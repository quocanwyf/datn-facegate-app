# 01.draft — Specs chưa approved

Spec mới và spec cần sửa sau review đặt tại đây, trạng thái `DRAFT`. Đã review nhưng chưa approved vẫn giữ trong thư mục này.

Ngày 14/11/2026, người dùng xác nhận duyệt toàn bộ 32 specs ban đầu; các file đã chuyển sang `02.approved`. Hiện thư mục này chưa có spec tính năng.

Khi được approved: bổ sung người/ngày/căn cứ review và approved, cập nhật trạng thái rồi chuyển file sang `02.approved`; sửa mọi liên kết liên quan.
